# Sales and Profit Analysis Dashboard (Excel)

This project focuses on analyzing sales and profit performance using **Microsoft Excel**. The dashboard was created using **Pivot Tables, Pivot Charts, Slicers, and KPI Cards** to transform raw sales data into meaningful business insights.

## Features

* Interactive **Sales & Profit Dashboard**
* **Pivot Table Analysis**
* **Sales by Category**
* **Profit by Year**
* **Customer Count Analysis**
* **State-wise Sales Performance**
* **Top Customers by Profit**
* **Monthly Sales Trends**
* **Slicers for Dynamic Filtering**

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning & Formatting

## Key Insights

* Analyzed overall **Sales and Profit performance**
* Identified **top-performing categories and customers**
* Studied **monthly and yearly trends**
* Compared **regional/state-wise performance**
* Created an interactive dashboard for easy decision-making

## Dashboard Preview

The dashboard provides a visual representation of business performance using charts and KPIs for better analysis and reporting.
